# Public Release Gate

- Confirm corporate ownership, assignments, and provenance for every file.
- Complete patent and standards-disclosure review.
- Scan all history and tags for secrets; rewrite history if required.
- Remove customer, Alliance, host, CUI, credential, topology, and production material.
- Inventory dependencies and licenses; resolve incompatible terms.
- Publish threat model, known limitations, supported versions, and release-signing process.
- Reproduce tests in a clean environment and publish artifact hashes.
- Ensure the verifier works without hosted-service access.
- Separate community and commercial endpoints.
- Complete privacy notice, DPA, service terms, SLA, and acceptable-use policy.
- Obtain legal review for licensing, patents, trademarks, export controls, privacy, blockchain operations, tax, sanctions, and token statements.
- Release as experimental until shutdown, tunnel I/O, enrollment, evidence verification, fail-closed behavior, rekey, replay, downgrade, packet-loss, and recovery tests pass end to end.
